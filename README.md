# Research Agent

Python CLI agent using LangChain + Groq LLM. Searches web (DuckDuckGo), queries Wikipedia, and saves structured reports (`topic`, `summary`).

## Usage
```bash
python main.py
```

## Tools
- `search_tool` — web search
- `wiki_tool` — Wikipedia query
- `save_tool` — save `output.txt`

## Requirements
```bash
pip install -r requirements.txt
```
